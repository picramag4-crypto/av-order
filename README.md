# AV Order

Первая версия Telegram Mini App для кофейни-бургерной АВ.

## Что уже работает
- категории и меню;
- варианты размеров/порций;
- корзина;
- самовывоз или доставка;
- доставка по Электрогорску +200 ₽;
- оплата наличными или QR-кодом при получении;
- имя, телефон, адрес, комментарий.

## Что подключим следующим этапом
- отправку заказа в Telegram сотрудникам;
- статусы заказа;
- кнопку «Принять»;
- уведомление гостю;
- админку / стоп-лист.

## Важно
Не храните BOT TOKEN в GitHub.
